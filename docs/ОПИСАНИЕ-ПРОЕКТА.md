# Tiankami — справочник по проекту

**Что это.** Сайт-каталог рогаликов Twitch-канала Tiankami: оценки, часы, статусы
прохождений, подборки, расписание стримов, соревнование «Мастер Игорей». Плюс игровые
элементы: «Улов дня» (рыбалка) и система редкости «драконьи яйца» (5 уровней).

Быстрый старт, правила и структура папок — в `../README.md`. Здесь то, что нужно знать,
когда что-то сломалось или предстоит менять данные.

## Деплой

Хостинг — GitHub Pages, адрес https://gerlod-os.github.io/tiankami. Пуш в `main` запускает
`.github/workflows/deploy.yml`: `npm ci` → `npm run build` → выкладка `dist`. Вручную ничего
делать не надо. Плюс суточная пересборка в `03:17 UTC`, чтобы данные таблицы подтягивались
без пуша.

**Адрес задан в одном месте:** `src/config/site.js` (`SITE_ORIGIN` + `BASE_PATH`). Он попадает
в `sitemap.xml`, `robots.txt`, canonical и `og:url` всех страниц. Сменишь адрес — правь там.

**Корень `https://gerlod-os.github.io/` даёт 404** — сайт живёт только в подпапке `/tiankami/`.

## Откуда данные

Источник — Google Таблица (ID в `src/config/dataSources.js`). Скрипт `scripts/sync-data.js`
скачивает её и кладёт в `src/data/`:

| Файл | Содержимое |
|---|---|
| `games.json` | игры |
| `collections.json` | подборки |
| `schedule.json` | трансляции и расписание |

Дальше сайт работает на локальных JSON. Живая сверка из браузера убрана 17.10: она не умела
доставать гиперссылки и тянула 250+ КБ с Google на каждый визит. Свежесть обеспечивает
пересборка по расписанию.

Обложки Steam подбираются без ключей: `scripts/steam-covers.mjs` берёт обложку по `appId`,
затем через поиск Steam со сверкой названия. Опечатки — `src/data/steam-name-aliases.json`,
ручные правки — `src/data/steam-overrides.json`.

## Страницы

`/` — главная, `/catalog` — каталог, `/catalog/:slug` — игра, `/collections` — подборки,

## Грабли, на которые уже наступали

1. **Синк затирал данные без сети.** `sync-data.js` при ошибке скачивания писал пустые `[]`
   в `src/data/*.json`. Исправлено: при пустом ответе прежний файл не перезаписывается.
2. **Редактор дописывает в `index.html` атрибут `data-page-node-id`.** Из-за этого пререндер
   вставлял пустоту и получались пустые страницы. Исправлено в `scripts/prerender.mjs`:
   открывающий тег ищется с любыми атрибутами.
3. **React #418 — расхождение серверной и клиентской разметки.** Лечилось правкой
   `useCounter`. Если вернётся — смотреть компоненты, у которых стартовое значение зависит
   от `window`.
4. **Имя канала на YouTube — «Tian Kami» с пробелом.** Из-за этого проверка авторства
   считала чужими все видео со ссылками и прятала плеер. Сравнение теперь без пробелов.
   Урок: сверять отображаемое имя с тем, что отдаёт `noembed.com`, а не с конфигом.
5. **Плеер YouTube автозагрузкой тянул ~1,2 МБ на каждой странице игры.** Теперь в разметке
   только постер, `iframe` подставляется по клику.

## Что не сделано

- Ссылки YouTube у части игр: в ячейках таблицы текст «Ссылка на плейлист» или «Нет»,
  гиперссылки нет физически. Закрывается только владельцем в таблице.
- Обложки у трёх игр (Against the Moon, Chaos Zero Nightmare, SAROS) — в Steam их нет,
  остаётся заглушка.
- Суббота в календаре Twitch: событие подписано «раз в две субботы», а правило в календаре —
  `FREQ=WEEKLY`, то есть каждую. Сайт показывает то, что в календаре.
