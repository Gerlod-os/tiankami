### Поток данных

```
Google Таблицы (TSV/CSV)
    ↓ npm run sync
src/data/*.json (games, collections, schedule)
    ↓ import
DataProvider (React Context)
    ↓ useData()
Страницы → Компоненты
```

### SSR / Prerendering

1. `vite build` собирает бандл с SSR (`entry-server.jsx`)
2. `scripts/prerender.mjs` рендерит 450+ страниц в `dist/`
3. Каждая страница получает статичный HTML + JSON-данные inline
4. На клиенте React гидратирует статичный HTML через `hydrateRoot()`

## 3. Страницы

### 3.1 Главная (`/`)

**Компонент:** `HomePage`

**Блоки:**

1. **LIVE-баннер** — появляется, когда Тиан в эфире
2. **Hero-секция** — последняя сыгранная игра (обложка на фоне, название, жанр, оценка, статус, дата) + виджет Twitch + логотип канала
3. **Статистика** — 4 карточки с анимированными счётчиками: всего рогаликов, пройдено, часов сыграно, подборок
4. **Улов дня** — случайная игра из базы (`CatchOfDay`)
5. **MEME ALERTS** — ссылка на Discord для отправки мемов на стрим
6. **Ближайший стрим** — дата, время, игра + обратный отсчёт (`Countdown`)
7. **Подборки от Тиана** — 4 карточки (макс. 4 из `collections`)
8. **Топ игр** — 8 игр по оценке (`topRated`)

**SEO:** `usePageMeta({ title: "Tiankami — каталог рогаликов", description: "..." })`

### 3.2 Каталог (`/catalog`)

**Компонент:** `CatalogPage`

**Функциональность:**

- **Поиск** (64px, glass-стиль) — мгновенный дропдаун с рекомендациями: популярные игры, жанры, сеттинги, особенности
- **Горячая клавиша** — `/` фокусирует поиск
- **Фильтры-чипсы** (сворачиваемые):
  - Жанр (мульти-селект, макс. 2 в ряд)
  - Статус (любой / любой из списка)
  - Год выхода (select)
  - Минимальная оценка (любая / 6+ / 8+ / 9+ / 10+)
  - Сложность (любая / лёгкие 1-4 / средне 5-7 / хардкор 8-10)
  - Часы (любые / <10 / 10-50 / 50-100 / 100+)
  - Только с кубком МИ (toggle)
- **Сортировка:** недавние / по оценке / по часам / по дате выхода / по прогрессу / по алфавиту
- **Пагинация:** по 24 карточки + кнопка "Показать ещё"
- **Пустое состояние** — случайная фраза + 3 топ-игры
- **URL-параметры:** `?q=`, `?genre=`, `?collection=`

**SEO:** `usePageMeta({ title: "Каталог рогаликов — Tiankami" })`

### 3.3 Страница игры (`/catalog/:slug`)

**Компонент:** `GamePage`

**Блоки:**

1. **Hero 70vh** — обложка в рамке + фоновая обложка (120% ширины, mask-gradient вниз) + хлебные крошки
2. **Название** — крупный заголовок, жирный шрифт для хардкорных игр (complexity ≥ 8)
3. **MITrophy** — если игра участница «Мастер Игорей»
4. **Оценка** — огромная цифра (7xl-8xl) с glow-эффектом
5. **Детали** — компонент `GameDetails` (таблица характеристик)
6. **Похожие игры** — карусель в стиле PlayStation с навигацией стрелками и клавиатурой

**SEO:** динамический title, description, OG image

### 3.4 Подборки (`/collections`)

**Компонент:** `CollectionsPage`

**Отображение:**

- Hero-секция с маскотом «Коллекция»
- Сетка карточек подборок (3 колонки)
- Золотая подборка выделена золотой карточкой + RarityEgg legendary
- Остальные — стандартные карточки с CollectionIcon
- На каждой: название, описание, CoverFan (веер обложек), список топ-игр с рангами

### 3.5 Подборка (`/collections/:slug`)

**Компонент:** `CollectionPage`

**Отображение:**

- Hero с названием подборки и описанием
- Список игр с рангами (#1, #2, #3...)
- RarityEgg для каждой игры

### 3.6 Обо мне (`/about`)

**Компонент:** `AboutPage`

**Блоки:**

1. **Hero** — маскот «Кроассан» + биография (Сергей / Тиан)
2. **Поддержка** — ссылки на Twitch/YouTube/Discord + блок MEME ALERTS + маскот «Копилка»

### 3.7 Расписание (`/schedule`)

**Компонент:** `SchedulePage`

**Блоки:**

1. **Ближайший стрим** — большая карточка + кнопка «В календарь» (ICS-файл)
2. **Следующие 3 стрима** — компактные карточки
3. **Прошедшие стримы** — последние 5
4. **Форма предложения** — `ScheduleForm`

**ICS-генерация:** клиентская генерация `.ics` файла для добавления в календарь

### 3.8 Мастер Игорей (`/mi`)

**Компонент:** `MIPage`

**Отображение:** список игр, в которых Тиан проводил «Мастер Игорей» (hasMI === true)

**Назначение:** Обёртка всех страниц

**Назначение:** Глобальный контекст данных (React Context API)

**Назначение:** Карточка игры для каталога/главной

## 6. Утилиты

### 6.1 normalize.js

**Функции:**

- `normalizeStatus(raw)` — нормализация статусов (синонимы → единый справочник)
- `normalizeGameRow(row, colIndex)` — парсинг строки TSV в объект игры
- `buildColIndex(headerRow, firstDataRow)` — определение индексов колонок из заголовка
- `normalizeGames(rows)` — полный парсинг TSV в массив игр

## 10. Ключевые правила

1. **Steam API не дёргаем** — обложки только с CDN: `cdn.cloudflare.steamstatic.com/steam/apps/{appId}/header.jpg`
2. **noembed ≤ 20 запросов за сессию** — проверка авторства YouTube, кэш бессрочный
3. **Twitch-статус** — кэш 5 мин, аватар — 24 ч (decapi, без ключей)
4. **Подборки парсятся построчно** — колонки «гуляют»
5. **Даты** — только `parseRuDate` (DD.MM.YYYY / YYYY-MM-DD)
6. **manualChunks** — только функцией (Vite 8 = rolldown)
7. **Google Fonts не используем** — шрифты через @fontsource
8. **SSR детерминирован** — рандом только после mount на клиенте
